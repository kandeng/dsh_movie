# Character Arc and Conflict

Characters are defined by the choices they make under pressure, and change is
only believable when it is earned through conflict. This skill constructs a
protagonist's arc from a **want** (conscious goal) and a **need** (unacknowledged
truth), then layers conflict so the script keeps forcing the choice between them.

## The arc

1. **Want** — what the character consciously pursues (the plot engine).
2. **Need** — what the character must learn or relinquish (the theme engine).
3. **Flaw/ghost** — the wound or false belief that keeps the need hidden.
4. **Turn** — the moment the character chooses the need over the want (or
   tragically refuses). Place it at the climax.

Map the arc across the acts: the flaw protects the character in Act I, is
challenged in Act II, and is confronted in Act III.

## Layers of conflict

- **Inner** — want against need; the character at war with themselves.
- **Interpersonal** — the character against allies, rivals, and intimates whose
  own wants collide.
- **External** — the character against the world, institutions, nature, or time.

Strong scenes run at least two layers at once so dialogue and situation pull in
different directions.

## Working steps

1. State want, need, and flaw in one line each.
2. For each act, name the pressure that forces the character closer to the turn.
3. Give the antagonist a coherent want that directly blocks the protagonist's.
4. Check every major decision is costly — a choice with no price is not character.
5. Verify the ending reflects a change (or a deliberate, tragic refusal to change).

## Output

A one-page arc sheet plus a conflict-layer annotation for each key scene.
